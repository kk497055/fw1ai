# Firstwave Solutions LLC

Company website at https://fw1ai.com, deployed from the root of `main` using GitHub Pages. `CNAME` preserves the custom domain.

## Local preview

Run `python3 -m http.server 8765` and open http://localhost:8765.

## Files

- `index.html`: company positioning, services, project process and inquiry form.
- `styles.css`: responsive design and reduced-motion support.
- `script.js`: mobile navigation and progressive form submission.
- `favicon.svg`: Firstwave mark.
